# Diagramas

Documentação do modelo de entidades implementado no backend Spring Boot, conferida em 21/11/2026.

- [Diagrama de classes UML](diagrama-classes.md): fonte editável em Mermaid, com oito entidades, dois enums e cardinalidades.

Os documentos incluem ParticipacaoAtleta e a referência opcional das estatísticas antigas à participação, sem expor dados do banco. Uma exportação para PDF ou PNG poderá ser preparada caso seja exigida na entrega.
